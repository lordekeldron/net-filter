# Ícones

Coloque aqui os arquivos de ícone da extensão:

- `icon16.png` (16×16)
- `icon48.png` (48×48)
- `icon128.png` (128×128)

Você pode gerar ícones simples em https://favicon.io ou qualquer editor de imagens.
Sugestão: escudo azul (#1d9bf0) com fundo escuro.

Enquanto os PNGs não existirem, o Chrome pode mostrar um ícone padrão de extensão.
